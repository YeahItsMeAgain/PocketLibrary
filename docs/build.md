# Building PocketLibrary for Android

This is the headless build path: no Android Studio, no emulator, no device, no
`sudo`. Everything lives under `$HOME`.

Verified on 2026-11-24 with the versions listed below.

| Component | Version / path |
|---|---|
| JDK | Temurin 21.0.9+10 (`$HOME/tools/jdk-21`) |
| Android SDK | `$HOME/Android/Sdk` (cmdline-tools `latest`) |
| SDK platform | `platforms;android-36` |
| Build tools | `build-tools;36.0.0` |
| NDK | `28.2.13676358` (`$HOME/Android/Sdk/ndk/28.2.13676358`) |
| Rust | 1.99.0 + `aarch64-linux-android` |
| Tauri CLI | 2.12.6 (`@tauri-apps/cli`) |
| Tauri crate | 2.12.7 |
| Gradle wrapper | 9.6.1 (generated by `tauri android init`) |
| Android Gradle Plugin | 9.3.1 (generated by `tauri android init`) |
| Kotlin | 2.2.10 |
| Node / npm | 24.21.0 / 11.19.0 |

## 1. Prerequisites

Everything below is user-space. `scripts/android-env.sh` exports the paths; source
it in every shell that builds:

```bash
source scripts/android-env.sh
```

It sets `JAVA_HOME`, `ANDROID_HOME`, `ANDROID_SDK_ROOT`, `NDK_HOME`, and `PATH`.

### JDK 21 (Temurin)

```bash
mkdir -p "$HOME/tools"
curl -L -o /tmp/jdk21.tar.gz \
  "https://github.com/adoptium/temurin21-binaries/releases/download/jdk-21.0.9%2B10/OpenJDK21U-jdk_x64_linux_hotspot_21.0.9_10.tar.gz"
tar -xzf /tmp/jdk21.tar.gz -C "$HOME/tools"
mv "$HOME/tools/jdk-21.0.9+10" "$HOME/tools/jdk-21"
```

Gradle needs a full JDK (not a JRE) because it runs `javac`/`keytool`.

### Android command-line tools

```bash
export ANDROID_HOME="$HOME/Android/Sdk"
mkdir -p "$ANDROID_HOME/cmdline-tools"
curl -L -o /tmp/cmdline-tools.zip \
  "https://dl.google.com/android/repository/commandlinetools-linux-15859902_latest.zip"
unzip -q /tmp/cmdline-tools.zip -d "$ANDROID_HOME/cmdline-tools"
mv "$ANDROID_HOME/cmdline-tools/cmdline-tools" "$ANDROID_HOME/cmdline-tools/latest"
```

### SDK packages, NDK, and the Rust target

```bash
export PATH="$HOME/tools/jdk-21/bin:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools:$PATH"
yes | sdkmanager --sdk_root="$ANDROID_HOME" --licenses
yes | sdkmanager --sdk_root="$ANDROID_HOME" --install \
  "platform-tools" \
  "platforms;android-36" \
  "build-tools;36.0.0" \
  "ndk;28.2.13676358"
rustup target add aarch64-linux-android
```

`sdkmanager` prints a deprecation warning ("use Android CLI instead") on this SDK;
it is harmless and `sdkmanager` still works.

## 2. SDK 37 → 36 fallback

Tauri 2.12's Android template pins `compileSdk = 37` and `targetSdk = 37`, but this
machine's `sdkmanager` does not offer `platforms;android-37`. Install 36 and edit
`src-tauri/gen/android/app/build.gradle.kts`:

```kotlin
android {
    compileSdk = 36          // was 37
    defaultConfig {
        minSdk = 24
        targetSdk = 36       // was 37
    }
}
```

Leave `minSdk = 24`. AGP 9.x supports API 36. **`tauri android init` overwrites
`gen/android`, so re-apply this edit if you regenerate the Android project.**
Put the edit immediately after `tauri android init` and before the first build.

## 3. Initialize and build

```bash
source scripts/android-env.sh
npm install                     # if node_modules is missing
npm run tauri android init -- --ci
# re-apply the compileSdk/targetSdk 36 edit from section 2, plus the release
# signing config from section 6
npm run tauri android build -- --apk --target aarch64 --ci
```

Release is the default build. Add `--debug` only when you specifically need a
debuggable APK.

`init` also installs the armv7/i686/x86_64 Rust targets; that is expected. Only
`aarch64` is needed for a phone build.

The first build downloads Gradle 9.6.1, AGP, Kotlin, and Maven dependencies and
takes 10–20 minutes. Later builds are much faster. Tauri prints the APK path at
the end.

## 4. APK output

Release, arm64 only (the default):

```
src-tauri/gen/android/app/build/outputs/apk/universal/release/app-universal-release.apk
```

Release builds are minified and signed with the release key, so they are
roughly 10–20 MB. Use `--split-per-abi` if you want per-ABI release APKs.

Debug output, only with `--debug`:

```
src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk
```

A verified debug artifact (2026-11-24) was **300,318,672 bytes (286 MiB)**:
debug builds keep Rust symbols (the `.so` alone is ~165 MB) and store native
libraries uncompressed. Both variants report `native-code: 'arm64-v8a'`,
`package: app.pocketlibrary`, `minSdkVersion 24`, `targetSdkVersion 36`; the
debug APK is signed with the Android debug key (`CN=Android Debug`).

## 5. Verification

```bash
source scripts/android-env.sh
APK=src-tauri/gen/android/app/build/outputs/apk/universal/release/app-universal-release.apk

"$ANDROID_HOME/build-tools/36.0.0/apksigner" verify --print-certs "$APK"
"$ANDROID_HOME/build-tools/36.0.0/aapt2" dump badging "$APK" | head -20
sha256sum "$APK"
```

A correctly signed release APK reports the release certificate
(`CN=PocketLibrary, O=Personal, C=US`), **not** `CN=Android Debug`. The exact
certificate digest and APK SHA-256 are printed by the commands above; re-check
them after each build rather than trusting a stale value.

The verified debug APK reported `Signer #1 certificate DN: C=US, O=Android,
CN=Android Debug`, SHA-256 digest
`c9612c660f5ea8abeb58d2e9b335edc7951e0513f79d4758c4a1171782d86691`; its APK
SHA-256 was
`10303dad7f2b40704c08e0f4abdedf26f97981bf40452a59075618e6c415c144`.

## 6. Release signing

The release build is signed from environment variables read by
`src-tauri/gen/android/app/build.gradle.kts`:

| Variable | Purpose |
|---|---|
| `POCKETLIBRARY_KEYSTORE` | Absolute path to the keystore |
| `POCKETLIBRARY_KEYSTORE_PASS` | Store/key password (PKCS12 uses one password) |
| `POCKETLIBRARY_KEY_ALIAS` | Key alias, defaults to `pocketlibrary` |

`scripts/android-env.sh` exports the first two automatically when the defaults
below exist, so the normal workflow is just:

```bash
source scripts/android-env.sh
npm run tauri android build -- --apk --target aarch64 --ci
```

A release build with the variables missing fails at Gradle configuration time
instead of producing an unsigned APK. Debug builds do not need them.

The release keystore already exists:

- keystore: `$HOME/.android-keys/pocketlibrary-release.jks` (PKCS12, RSA 4096,
  alias `pocketlibrary`, 10,000 days, mode 600)
- password: `$HOME/.android-keys/pocketlibrary.pass` (mode 600)

These are outside the repo and must never be committed. The release certificate
is **not** the debug certificate, so a release APK cannot be installed over a
debug install: uninstall the debug app first (`adb uninstall app.pocketlibrary`,
or uninstall from the phone's app settings) before sideloading the release APK.

To regenerate from scratch (this replaces the key, so existing installs must be
uninstalled, and future builds need re-signing):

```bash
mkdir -p "$HOME/.android-keys" && chmod 700 "$HOME/.android-keys"
openssl rand -base64 48 | tr -d '\n' > "$HOME/.android-keys/pocketlibrary.pass"
chmod 600 "$HOME/.android-keys/pocketlibrary.pass"
PASS=$(cat "$HOME/.android-keys/pocketlibrary.pass")
keytool -genkeypair -v \
  -keystore "$HOME/.android-keys/pocketlibrary-release.jks" \
  -storetype PKCS12 \
  -keyalg RSA -keysize 4096 -validity 10000 \
  -alias pocketlibrary \
  -dname "CN=PocketLibrary, O=Personal, C=US" \
  -storepass "$PASS" -keypass "$PASS"
chmod 600 "$HOME/.android-keys/pocketlibrary-release.jks"
```

### Re-applying after `tauri android init`

The signing config lives in `src-tauri/gen/android/app/build.gradle.kts`.
`tauri android init` regenerates the whole `gen/android` tree and overwrites it,
so after any re-init you must re-apply:

1. the `compileSdk`/`targetSdk` 36 edit from section 2, and
2. the environment-driven `signingConfigs`/`buildTypes.release` block from this
   section (or copy the file back from git).

The same applies to the `optimization`/ProGuard settings in that file. The
keystore itself is outside the repo and unaffected by re-init.

### Version codes

Android refuses to install a `versionCode` less than or equal to the installed
one. Tauri derives it from `version` in `tauri.conf.json`
(`major*1_000_000 + minor*1_000 + patch`), or set
`bundle.android.versionCode` explicitly. Bump the app version before sideloading
a changed build.

## 7. Playwright smoke test (web layer)

The web UI is validated in headless Chromium at a 390×844, DPR 3, touch viewport:

```bash
npx playwright install chromium   # once
npm run test:e2e
```

The config (`playwright.config.ts`) starts the Vite dev server at
`http://localhost:1420` automatically. Screenshots, traces, and reports land in
`test-results/` and `playwright-report/`, both gitignored. Do not commit them.

## 8. Per-merge checks

```bash
cargo test --manifest-path core/Cargo.toml   # headless catalog tests
npm run build              # tsc && vite build
npm run test:e2e           # Playwright smoke
cargo clippy --manifest-path src-tauri/Cargo.toml --target aarch64-linux-android --all-targets -- -D warnings
npm run tauri android build -- --apk --target aarch64 --ci
```

`source scripts/android-env.sh` first: it now exports the NDK C compiler for
`aarch64-linux-android`, which the bundled SQLite in `libsqlite3-sys` needs.

The core crate (`core/`) has no Tauri dependency, so its tests run on this
headless host. `cargo test` / host-target `cargo clippy` for `src-tauri` still
need desktop GTK/WebKit development packages (`glib-2.0.pc`,
`webkit2gtk-4.1`, …), which are not installed on this no-sudo box. Use the
`--target aarch64-linux-android` clippy invocation above (verified green) and
the APK build to exercise the Tauri shell; run host `cargo test` for it on a
machine with the Tauri desktop prerequisites.

## 9. Troubleshooting

- **`platforms;android-37` not found**: expected here; see section 2.
- **`compileSdk 37` errors about a missing platform after regenerating**: the
  SDK override was lost; re-apply it.
- **`JAVA_HOME`/JDK toolchain errors**: point `JAVA_HOME` at the Temurin JDK, not
  a JRE. `java -version` must show 21.
- **`clang`/linker errors naming the NDK**: `NDK_HOME` must be the exact version
  directory (`.../ndk/28.2.13676358`), not the `ndk` parent.
- **Gradle lock / stale build**: stop daemons with
  `src-tauri/gen/android/gradlew --stop`, then rebuild. Delete
  `src-tauri/gen/android/.gradle` or `build` only as a last resort.
- **`tauri android build` is slow the first time**: it downloads Gradle, AGP, and
  Maven artifacts. Use a long timeout; do not kill it mid-download.
- **No emulator**: this host has no `/dev/kvm`. Verification is `apksigner` +
  `aapt2` + Playwright, plus sideloading on a physical phone via `adb`.
- **`adb` has no device**: expected. `tauri android dev/run` need a device;
  `init/build` do not.
- **APK is ~129 MiB**: debug builds keep Rust symbols. Release builds are much
  smaller.
