# 27: Moving several books in quick succession stopped working

> *This was generated by AI during triage.*

**Category:** bug
**Status:** resolved

**Cause:** The drag preview and ghost stayed on screen until the move command resolved, and a late success could write a stale book order over a newer move.

**Fix:** Moves are now painted optimistically and the preview is cleared immediately; a failed command rolls back. Playwright covers two overlapping drags with a deliberately slow move command.

**Verification:** New quick-succession drag test plus the existing reorder and cross-shelf tests pass.
