# 25: “The Whisper Man” still showed as “MAN” after 0.1.4

> *This was generated by AI during triage.*

**Category:** bug
**Status:** resolved

**Cause:** 0.1.4 repaired titles only during a rescan. The open library had not been rescanned, so the stored `MAN` row survived the update.

**Fix:** The catalogue now repairs a short stored title from its download history or filename whenever the database opens. Existing libraries are fixed on the next launch without a rescan. Normal titles are untouched.

**Verification:** Core unit tests cover download-history repair and a normal title staying unchanged.
