# 08: PDF reader

**What to build:** PDFs open in the same reader shell with the same chrome, Contents, bookmarks, progress, themes, and position memory, but as fixed pages: fit-width, pinch zoom, and page jump.

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] A PDF opens in the reader with the same top/bottom bars and tap zones
- [ ] Fit-width is the default; pinch zoom and page-number jump work
- [ ] Paper/Sepia/Night apply as a tint without reflowing the page
- [ ] Position resumes at the same page; progress reflects pages read
- [ ] Contents lists the PDF outline where present; bookmarks work
- [ ] Font-size controls are replaced by zoom and text reflow is absent
