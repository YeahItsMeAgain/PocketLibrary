# 26: PDF cover showed a page of words

> *This was generated by AI during triage.*

**Category:** bug
**Status:** resolved

**Cause:** PDF covers were always page one. For a PDF whose first page is a text title page, the cover became a wall of words.

**Fix:** Cover extraction samples the first four pages and chooses the first jacket-like page by ink and colour. If none qualifies, the generated plate is used instead of an unrelated text page.

**Verification:** Core fixture with a white text title page and a coloured jacket page asserts the jacket is chosen.
