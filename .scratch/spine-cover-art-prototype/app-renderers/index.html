The chain

What each renderer consumes

Every book below was fed through the real v8-app Rust/ONNX binary on the host. The app-renderer layer never runs detection, masks or inpainting itself: it reads run.json, applies the pipeline's final.crop_box_work to art.jpg, and composes the study.

  1. DownloadOriginal cover, per book.
  2. v8-appDBNet → mask → crop search / fill → QA.
  3. Outputart.jpg, spine-2x.jpg, run.json, qa.json.
  4. RenderersFull-bleed · art-only · wrap · design system.

Execution split

Host gallery now. Native pipeline → WebView on the APK.

These pixels were rendered in Chromium from v8-app's host output. The APK in android-renderer/out/ bundles this exact renderer; its native Activity runs the same Rust/ONNX pipeline on the phone and hands the run directory to a WebView. This environment has no adb device or emulator, so the APK integration is built and package-verified here, not device-run. The v8 pipeline itself was device-proved separately.
