PocketLibrary · throwaway test build

One art route, four spine styles

This is the v8 pipeline plus an on-device WebView renderer. Generate a spine from a sample, device image or cover URL, then open the renderer to see Full-bleed, Textless, Wrap, Hybrid, Cloth and Editorial.

Download renderer test APK 21.2 MB · arm64-v8a · Android 8.0+ · package app.pocketlibrary.spinetest

Test flow

  1. Install and open v8 Spine Test.
  2. Pick a sample or fetch a cover URL; fill title/author/pages.
  3. Tap Generate spine on device.
  4. Tap Render four spine styles on device.
  5. Check Full-bleed, Textless, Wrap, Hybrid, Cloth and Editorial; compare with the native v8 spine.

Important

LaMa is not packaged. Text-heavy covers may return review or fallback. Dune and Rock Paper Scissors are intentional review cases in the gallery. Cloth is the safe fallback for review covers.

This is a debug-signed test APK, not the release app. It installs alongside PocketLibrary.
