# PocketLibrary spine studies

Throwaway design prototypes, not production code.

**Open:** `http://<host>:4173/spine-cover-art-prototype/` (redirects to v2) or use the study dock arrows on any page.

## Studies

1. **v2 — High-res full-bleed**  
   Real covers, wider spine crop, top cap and title rail.

2. **v3 — Textless artwork**  
   Genuine public-domain paintings plus OCR/LaMa reconstructions.

3. **v4-wrap — Wrap engine**  
   Page-count spine width, continuous back/spine/front wrap, measured type fitting.

4. **v4-generative — Generative removal**  
   FLUX.1 Kontext reconstruction of large typography, with honest failure cases.

5. **v6 — Design directions**  
   Editorial, Clothbound and Hybrid; the current recommendation is Hybrid.

6. **bookcover-js reference**  
   Deep source audit and hands-on spine-only SVG/PNG test.
