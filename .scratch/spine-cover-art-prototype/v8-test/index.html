PocketLibrary · throwaway test build

Cover → spine, on the phone

This APK runs the v8 Rust/ONNX pipeline on-device. It accepts a bundled sample, a device image, or a cover URL, then generates a 52 × 236 spine with pass/review/fallback QA.

Download v8 spine test APK 19.7 MB · arm64-v8a · Android 8.0+ · package app.pocketlibrary.spinetest

Install

  1. Open the link on the Android phone.
  2. Allow install from this browser/file source if prompted.
  3. Install v8 Spine Test.
  4. Open it. The first run copies ~13 MB of detection/recognition models out of the APK.

What to test

  • Pick a bundled sample, a device image, or fetch a cover URL.
  • Fill title/author/page count, then tap Generate spine on device.
  • Check the source, 52 × 236 spine, typographic fallback, contact sheet and QA summary.
  • Export spine + run.json to Downloads if you want to inspect the result.

Important

LaMa (208 MB) is not packaged in this test build. Covers where no text-free crop is available use the flat-fill route and may return review or fallback. That is the pipeline's honest result, not a crash.

This is a debug-signed test APK, not the PocketLibrary release app. It will install alongside the normal app.
