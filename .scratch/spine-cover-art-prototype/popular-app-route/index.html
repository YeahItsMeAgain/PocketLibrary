Reproducibility statement

The pack is a bonus. The route is the app.

The Popular Editions Pack is now a bonus, not the reproducibility mechanism. Any popular cover goes through v8-app on-device. The pack remains optional: a rights-cleared fast path and a fallback when the app route is unavailable.

Reference/bookcover-js is a design reference, not a reproducibility route. It is a manual export tool with hand-entered width and type; it does not turn a random cover into a spine.

One route, five covers

What runs in the app

  1. 01Select or downloadA random book and its cover. Bundled samples are convenience inputs, not a per-book lookup.
  2. 02v8-app Rust / ORTDBNet text detection, Lab colour mask, line completion, flat fill, optional LaMa, crop search, QA.
  3. 03Pass · review · fallbackThe pipeline decides honestly. A failed reconstruction ships the typographic fallback beside the candidate.
  4. 04v6/v7 renderMeasured Hybrid label or full-width Art-only at 52 × 236, with 2× output.

Every image below is produced by the same Rust pipeline that is packaged in the v8-android APK. The host run is the app code path, not a desktop Python precompute.

Study · Generative art

The FLUX route is superseded

The old v4 study used a hosted FLUX.1 Kontext Space or Pollinations, hit anonymous GPU quota, and required human review. That is not a reproducibility route. v8-app is automatic and on-device; the inpaint is the generative step.

Superseded
v4-generative hosted / manual FLUX

Quota-bound, keyless only until the quota ran out, not mask-conditioned, and every result needed a human. Kept as a design record, not a pipeline.

v8-app automatic / on-device

Rust + ONNX Runtime. DBNet + colour masking + flat fill or optional LaMa + crop search + QA. No key, no hosted Space, no hand mask.

What remains

Tauri integration

Already app-capable

  • Rust pipeline and ONNX models run in the packaged arm64 APK.
  • ONNX Runtime is the only native dependency; no Python, torch or desktop step.
  • Automatic pass / review / fallback with a rendered cloth fallback.
  • The v6/v7 Hybrid and Art-only renderers are DOM + Canvas only.

To wire into Tauri

  • Move the pipeline call behind a Tauri command and cache model extraction in app-private storage.
  • Ship det.onnx + rec.onnx + ORT (≈33 MB); keep LaMa as an opt-in download.
  • Feed the generated art into the existing spine renderer; persist the 52 × 236 / 2× output.
  • Add the pack as an optional enhancement layer, never as the only path.
  • Re-test cold start, memory and latency on the target phone; device proof is the remaining gate.
