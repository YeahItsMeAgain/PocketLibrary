Install

Sideload it over the previous release, or do a clean install if your phone has a debug or differently signed PocketLibrary.

  1. Download the APK on the phone (or copy it over).
  2. Open the file. If Android blocks it, allow Install unknown apps for the browser or file manager you used.
  3. If an older PocketLibrary is installed: a release build with the same key installs over it. A debug build or a build signed with another key must be uninstalled first; Android will refuse the update otherwise.
  4. Open PocketLibrary and import or pick a book. The spine models are extracted from the APK on the first Generate.

What to test

Basic flow

  • Open a book → Spine → Generate spine.
  • Wait through the progress labels, then check the verdict and the six style canvases.
  • Switch Wrap and Cloth: the preview should re-render instantly without generating again.
  • Go back and reopen the book: the saved result should still be there.

Edge cases

  • Try a text-heavy commercial cover such as Rock Paper Scissors; it should land on Review with a Use Cloth action.
  • Tap Use Cloth: it should apply immediately, with no second generate.
  • Check the 33 px shelf spine after the detail view.
  • Rotate the phone and confirm the Spine section does not overflow or clip.

Known limits

This is a test build

  • Models are bundled in this APK for testing. The production model downloader/cache is not part of this build yet.
  • arm64 only. It will not install on 32-bit, x86, or an emulator without arm64 translation.
  • ~63 MiB download plus ~41 MiB extracted models on first run. Leave roughly 120 MiB free.
  • Generate runs fully on the device. On a phone it is slower than the host timings in the evidence; the inpaint route can take noticeably longer than the crop route.
  • Release-signed, so it will not install over a debug build. Uninstall the old app first.
