Install

Sideload it over 0.1.18, or do a clean install if your phone has a debug or differently signed PocketLibrary.

  1. Download the APK on the phone (or copy it over).
  2. Open the file. If Android blocks it, allow Install unknown apps for the browser or file manager you used.
  3. If 0.1.18 is installed from this page: install straight over it. The release key is the same, the library is kept, and the database stays at schema 7.
  4. A debug build or a build signed with another key must be uninstalled first; Android will refuse the update otherwise.
  5. Open PocketLibrary. Spines start preparing automatically; on an existing library the backfill runs once at low priority, so the wall stays usable.

The shelf and reader, since 0.1.18

Smoked leather

  • Full-height art under a warm scrim. The cover strip is still the whole spine, but the title no longer relies on adaptive ink over raw art.
  • No foot band. The full author over two lines and the 5px label codes sit on the scrim's deepest 30%, so a shelf no longer reads as one black bar.
  • Reading is an oxblood drape over the shelf lip; finished is a gold head ribbon. Neither ever enters the title box.
  • Titles fit. A single long word shrinks, per-column tracking is capped, RTL is measured in direction, and nothing clips.

One reading desk

  • The old top and bottom bars are gone. A brass pull and the percentage open the desk.
  • Type, theme, mode, contents, bookmarks, highlights and PDF page/zoom live in one 48% sheet.
  • Drag down to close; the sheet follows and springs back under threshold. Escape and back also close it.
  • Paginated EPUB reflows while the desk is open; scrolled EPUB and PDF overlay without repaginating.

Also in this build

  • The Studio preview paints the same spine as the shelf and follows a reading-status change live.
  • Cloth and Typography keep their boards and share the drape/gold-ribbon status language.
  • Cover validation and the Open Library HTTP seam now have tests.
  • The fast gate still runs with 4 workers; the drag-ghost pass gets extra time under load.

What to test

On the shelf

  • Install over 0.1.17 without uninstalling. Your shelf, reading state, labels and per-book styles should be intact.
  • Art spines should show cover art under the warm scrim, the author and label codes on the deep foot, and no dark band across the shelf.
  • A reading book carries an oxblood drape over the shelf lip; a finished book a gold ribbon at the head. Flip a status and watch the mark move.
  • Open a book in Edit, change its status, and confirm the Studio preview follows.

In the reader

  • Open a book: the page is clean except a brass pull and a percentage. Both open the desk; nothing else should.
  • Change size and theme, drag the desk down to close, and check that you land on the same text.
  • Try scrolled mode and a PDF: the desk should overlay without repaginating the page.
  • Check that Android back closes the desk first, then the reader.

Known limits

This is a test build

  • Models are still bundled in this APK for testing. The production model downloader/cache is not part of 0.1.19.
  • arm64 only. It will not install on 32-bit, x86, or an emulator without arm64 translation.
  • 64.98 MiB download plus ~41 MiB extracted models on first run. Leave roughly 120 MiB free.
  • Generation runs fully on the device. On a phone it is slower than the host timings in the evidence.
  • Release-signed, so it will not install over a debug build. Uninstall the old app first.
